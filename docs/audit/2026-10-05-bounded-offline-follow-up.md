   receives the frozen packet, precise defects and original rejected report/hash.
   The worker verifies the packet/report bindings, permits one correction, creates
   a fresh ephemeral model thread, and records old/new identities and context policy.
   Controller allocations and the original deadline continue unchanged. Original
   attempts remain in provenance. Author revisions retain their existing context.
2. **Operation-specific budget forecasts.** Allocations distinguish draft, revision,
   fresh audit, re-review, report correction and draft correction. Fresh scientific
   review forecasts use the largest relevant completed usage with 25% headroom,
   bounded below by the frozen prompt estimate plus 6,000 tokens. Unseen reviewers
   use a 20,000-token fallback. Historical repeated audit turns from the same agent
   are recognized as legacy retained-context repairs and remain charged without
   inflating fresh-call forecasts. Fresh repair usage informs a separate repair
   reserve. Increasing the ceiling no longer increases forecast floors. Revision
   admission protects all four reviews, repair capacity, practical author capacity
   and a 10,000-token final handoff; deferred reviewers cannot borrow those reserves.
   The initial author reservation also uses source size, repair and handoff needs
   rather than a floor proportional to the ceiling. Forecasts are not completion
   guarantees: unknown revised prompt size, model overhead and scientific objections
   can still cause a bounded partial result.
3. **Reviewed verifier evidence.** The existing finite-partition routine is reused.
   Its module now needs only Python >=3.11 standard-library dependencies. Receipts
   freeze exact source bytes as an artifact, expose code for packet review, and
   include a hash-checked installed-module invocation and deterministic expected
   output. The CLI refuses a mismatched implementation before verification. Stored
   implementation bytes are checked by quality assessment. Manuscript-local artifact
   references reuse existing publication evidence binding; no second release ledger
   or attachment execution mechanism is introduced. Finite output remains limited
   to its enumerated carriers and counterexample.
4. **Acceptance framing.** Author and specialist instructions distinguish the
   task-seeded false assertion from a documented historical publication. The revised
   acceptance brief requires its explicit refutation/counterexample, narrow source
   attribution and split compound claims. Independent semantic review and human
   approval remain separate. Bibliography markers remain release blockers.
